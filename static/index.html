设置
获取 Cookie 最简单的方式：在下方超星卡片里输入账号密码点「自动获取」；或浏览器登录目标网站 → F12 → 网络(Network) → 刷新 → 点第一个请求 → 请求标头 → 复制 Cookie

超星学习通

傻瓜式操作：直接输入你的超星账号密码，点「自动获取 Cookie」即可，系统会替你登录并保存（Cookie 只存本地）。
若自动登录失败（如需验证码），再用下面的手动方式。
备用：浏览器登录 mooc1-1.chaoxing.com → F12 → 网络 → 复制 Cookie；Cookie 过期后重新获取即可。

智慧树（知到）

傻瓜式操作：直接输入你的智慧树账号密码，点「自动获取 Cookie」即可，系统会替你登录并保存（Cookie 只存本地）。
若自动登录失败（如需验证码），再用下面的手动方式。
备用：登录 zhihuishu.com 后复制；失效后重新复制。
若自动抓取为空，可在知到里打开消息/通知页面，把地址栏 URL 粘到这里。
